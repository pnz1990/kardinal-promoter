# The Go test packages that read the repository's docs (docs/, README.md,
# mkdocs.yml, overrides/): ci.yml's docs-tests job runs them when a pull
# request changes the docs and no Go (#1903), so a docs edit that breaks one
# (a stale generated reference, a CLI line that no longer parses, a coverage
# anchor, a changelog link) fails the pull request instead of main.

# paths, by a string literal, a constant (built from pieces, or another
