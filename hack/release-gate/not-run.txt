# each line under "Not run by this gate", so a GO verdict does not read as
# proof of them.
#
# One line each: item | why the gate does not run it | evidence instead.
# The evidence is comma-separated: test/e2e/coverage.tsv row IDs (each must
# be covered), release.yml:<job> for a job of .github/workflows/release.yml,
# or matrix.txt:<suite> <minor> for a hack/e2e/matrix.txt job, which the
# nightly e2e-live run runs.
# A line without a reason or evidence, a line citing a row, job or matrix
# job that does not exist, and an empty list stop the gate before it runs
# anything.
