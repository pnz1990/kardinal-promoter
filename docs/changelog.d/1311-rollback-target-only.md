section: Changed

- **`kardinal rollback`, `kardinal promote` and the automatic rollback promote only the target environment** (#1311) — their versions set the new `spec.intent.targetOnly`. When another version of the Pipeline with the same artifacts was Verified in every environment upstream of the target, the new version carries that verification in the new `status.upstreamEvidence` and its Graph has only the target. The upstream environments keep what they run, and their gates, soak and freezes no longer hold an urgent rollback. The target's own gates still apply. A gate on the target that reads `bundle.upstreamSoakMinutes` or `upstream.<env>.soakMinutes` reads the carried soak, and the PR body's Upstream Verification table lists the carried verifications. Without such a verification, or with a verify gate on the target, the version goes through the upstream environments as before, and its `UpstreamEvidence` condition says why ([Multi-Environment Rollback](rollback.md#multi-environment-rollback)).
