- **The `soak` live suite, an enterprise day** (#2403): `TestSoak_EnterpriseDay` runs three teams on one release for an hour (`KARDINAL_E2E_SOAK_DURATION`): agents shipping and verifying, ServiceNow and Jira change requests answered by a change board that rejects one in ten, a person's approvals, PR review, the org's gates through `policyNamespaces` with consent, a 31-environment compact fleet and key-signed receipts with referrers under each team's registry prefix, with about 6 versions a minute. On a timer while the load runs it freezes agents, stops the line, upgrades the release (turning `perNamespace: required` on), has a team ship another team's image, rolls a failed release back by itself, kills the leader with no grace period and has a namespace consent. A checker (`test/e2e/framework/soak`) runs the invariants every three minutes (tenant isolation, receipts signed once and stored, only allowed verdicts counted, audit trails, under 1% reconcile errors, no panic or restart, memory flat) and the first violation ends the soak, dumps the estate and fails naming the invariant. It runs weekly in e2e-live.yml and in the release gate's soak set (`soak-enterprise-day`), never nightly or per pull request.
