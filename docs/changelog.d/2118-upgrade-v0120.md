- **Upgrading from v0.12.0** ([guide](upgrade.md#upgrading-from-v0120), #2118) — the steps from v0.12.0 to the next release, run as written by a new live suite, `upgrade-v0120`, on Kubernetes 1.35 and 1.37, while versions are in flight. Versions keep their Graphs, steps and PRs and finish; gates that hold a version keep holding it (approval, verify and freeze gates, and a gate edited after the upgrade, which now reaches the version); an AgentRun running at the upgrade finishes and counts; the PromotionReceipt and ChangeRequest kinds are installed and stay inert until you use them; a rollback after the upgrade changes its target environment alone.
