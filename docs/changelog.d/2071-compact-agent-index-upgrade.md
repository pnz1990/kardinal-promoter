---
section: Upgrade
---

- **The agent index changes format: wait for `CompactReady`, not `Ready`** (#2071, [The index format](actors.md#the-index-format)). Apply the new CRDs before the chart, as for every release: the AgentIndex gains `status.compactUsers` and `status.compactGroups`. During the `helm upgrade` the controller keeps writing the old format, which the new actor policies read too. It switches to the compact format once every replica runs the new release, so no older replica is left reading it. From then on the index's `Ready` condition is False (reason `CompactFormat`), and `CompactReady` says it is built. Change any script or check that waits for `--for=condition=Ready` on the AgentIndex to wait for `--for=condition=CompactReady`. The `kardinal` CLI reads the compact format from v0.13.0 on, so v0.13 CLIs keep working. Upgrade any CLI your agents run that is older than v0.13.0 before the controller: it cannot read the compact format, so it stamps an agent as a person or a bot, and the write is refused. After a `helm rollback` to v0.13, the v0.13 policies refuse the writes they check until a v0.13 controller has rebuilt the index in the old format, within seconds of its start. The old format is full at about 5,000 AgentIdentities.
