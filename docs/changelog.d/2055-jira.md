- **Jira change requests** (#2055, [Jira](change-requests.md#jira)). `provider: jira` opens issues through the REST API: version 3 on Jira Cloud, with the description as an Atlassian Document Format paragraph, or version 2 on Data Center with a personal access token. Each issue carries the promotion's correlation label, and a JQL search for that label finds it before any new create. The state follows the workflow: `rejectedStatuses` first, then `cancelledResolutions` (default `Won't Do`), then `approvedStatuses` or the `approvedStatusCategory` (default `done`). `spec.jira.project` is required in mode open (a CRD rule).
