section: Security
---

- **A verify gate that lists only agents counts only agents** (#2411). `verify.allowedAgents`, `allowedUsers` and `allowedGroups` are now one allowlist: an agent's verdict counts only when the gate lists the agent, and anyone else's only when the gate lists them in `allowedUsers` or `allowedGroups`. Only a gate that lists nobody at all still counts every person's and bot's verdict. Before, a gate that listed only agents also counted every person's verdict, so anyone whom the chart's approver or verifier role lets write a Verdict could pass it, including the "only the QA agent" example in [Agents as verifiers](agentic/verify-with-agents.md#how-verdicts-count). The Graph no longer copies such a verdict into the gate, the tally refuses it, and `kardinal verify` tells its writer that the gate counts only its agents and how to list people. Graphs render once more on upgrade (render version 4), so versions already promoting stop counting those verdicts too. `kardinal doctor` has a new check, "Verify gates of agents only", that names these gates.
