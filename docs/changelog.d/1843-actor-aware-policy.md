- **Actor-aware policy** ([page](agentic/policy.md), #1843) — gates see who created a version: `actor.*` (the verified actor stamp: human, agent, bot or controller, the agent and its sponsor) and `agent.*` (the agent's registration now, so a suspension holds its in-flight versions) in every gate expression ([CEL context](reference/cel-context.md#actor)). `actor.verified` refuses versions without a stamp.
- **Per-environment autonomy for agents** (#1843) — `environments[].agents: auto | approve | deny` on a Pipeline; with the AgentIdentity's `autonomy`, the stricter wins. kardinal adds a `kardinal-agents-<ceiling>` gate to every environment of an agent's version; people's versions are not affected ([Pipeline fields](reference/pipeline.md)).
- **The one-party rule** (#1843) — with `excludeAuthor`, an agent's sponsor cannot approve its work, an agent cannot approve its sponsor's, and two agents of one sponsor cannot approve each other's; `required: N` counts parties, so an agent and its sponsor are one vote ([Approvals](approvals.md#one-party-one-vote)).
- **Opt-in agent approvals** (#1843) — `approval.allowAgents` with `approval.allowedAgents`; an agent never counts on its own party's work ([Agents as approvers](approvals.md#agents-as-approvers)).
- **`approval.requiredWhen`** (#1843) — an approval policy that applies only while a CEL condition holds, for example `actor.kind == 'agent'`; `approvals.met` and `status.approvalRequired` say whether it held ([Approvals](approvals.md#require-approval-only-sometimes)).
- **Freeze agents, stop the line** (#1843, [page](agentic/freezes.md)) — `kardinal freeze --agents | --everyone [-n <ns>] --reason <why> [--for <d>]`, `kardinal unfreeze`, and `kardinal override <pipeline> <env> --freeze` for a verified, audited (`FreezeExempted`) exemption, which counts for at most a day from when the controller first sees it (`controller.freezeExemptionMaxMinutes`) and never for an agent (break-glass is for people). In the UI, a namespace's freeze right changes or lifts only the caller's own freezes of that namespace. A freeze is a ChangeWindow with `spec.freeze`; the controller holds every promotion it selects, in Graphs built before it too. The UI shows a banner and, with `ui.freezeControls`, offers Freeze agents, Stop the line and Unfreeze. The chart adds the `<release>-freezes` admission policy and the `<release>-freezer` ClusterRole.
